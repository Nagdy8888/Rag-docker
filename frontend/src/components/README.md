# frontend/src/components

React UI components for the RAG chat app.

## Main components

- **Sidebar.tsx** — Session list, Documents link, new chat.
- **ChatInterface.tsx** — Message list, input bar, streaming display, source cards.
- **InputBar.tsx** — Text input and send.
- **DocumentList.tsx** / **DocumentsPage.tsx** — Document upload and list.
- **SourceCard.tsx** — Single source citation (filename, snippet).
- **EmptyState.tsx** — Empty chat state.
- **ThinkingIndicator.tsx** — Shown while the agent is processing.

See [../../docs/guide/07-frontend-structure.md](../../docs/guide/07-frontend-structure.md) for data flow and state.

# frontend/src

React application source: entry point, App, components, API client, types.

## Contents

- **main.tsx** — React entry point.
- **App.tsx** / **App.css** — Root layout and routing.
- **index.css** — Global styles (e.g. Tailwind).
- **components/** — UI components (Sidebar, ChatInterface, DocumentList, etc.).
- **api/** — API client for backend (chat, documents, upload).
- **types/** — TypeScript types and interfaces.
- **assets/** — Images, icons, or other static assets.

See [../README.md](../README.md) and [../../docs/guide/07-frontend-structure.md](../../docs/guide/07-frontend-structure.md) for overview.
